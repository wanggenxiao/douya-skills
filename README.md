# 豆学堂 · 工程师 AI Skill 库

给土木/岩土工程师用的 AI Skill 合集。**不限专业**——物探、测量、检测、造价、施工、结构，凡是要读报告、写方案、出图、做汇报的活，路子是同一套。

---

## 什么是 Skill

Skill 是一套**开放规范**，不绑定任何平台。

一个 skill 就是一个文件夹，里面放一份 `SKILL.md`，写清楚"遇到这类活该怎么干"。AI 读到它，就按里面的方法做事——**相当于你把一位老师傅的经验，写成了 AI 能看懂的作业指导书**。

**同一个 skill，WorkBuddy、Claude Code、Kimi Code 都能用。** 学的是方法，不是某个软件的按钮。

---

## 怎么用（推荐：让 AI 自己拉）

打开 WorkBuddy，把下面这段**原样发给它**：

```
帮我做这几件事：
1. 找到你自己的 skill 目录在哪，告诉我完整路径
2. 把这个仓库拉下来：<仓库地址>
3. 把里面 skills/ 下的文件夹复制到你的 skill 目录
4. 告诉我需不需要重启你才能生效
做完列一下你现在能用哪些 skill
```

> **不用会 git，也不用自己敲命令——这件事本身就是让 agent 替你干活的第一次练习。**

装完之后，正常说人话就行，比如"把这份地勘报告转成文字"，AI 会自己判断该用哪个 skill。

## ⚠ 三句实话

1. **Skill 不是魔法。** 它是把做事的方法写清楚，AI 照着做。方法本身错了，AI 只会更快地做错。
2. **复杂 skill 吃模型智力。** 接的模型不够聪明时，步骤多的 skill 会跑歪。跑不动先换个聪明点的模型试，别急着怀疑自己。
3. **AI 提取的资料不能直接当事实用。** 尤其表格和公式。
   > **不要求 100% 准确，要求错误可发现。**
   > 结构计算要有校核，施工要有验收——没人指望一次做对，大家指望的是错了能查出来。
