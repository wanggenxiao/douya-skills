# 视频 → 逐字稿 → 中文笔记

> 豆学堂教学版。刷到一个好视频，想把它"读"下来而不是反复看，就用这个。

## 整条链

```
B站链接 / 本地视频
  ↓ ① 下载（只要声音就够）
  ↓ ② 抽成 16k 单声道 wav
  ↓ ③ 本地语音转文字（SenseVoice，免费、不上传）
  ↓ ④ AI 通读，整理成笔记
结构化中文笔记 .md
```

所有产物和视频**放在同一个文件夹**，别散到别处。

## 第 0 步：先检查环境（第一次用时做）

依次检查，缺什么就**告诉用户要装什么、多大、大概多久，用户同意再装**：

| 工具 | 干什么 | 检查 | 安装 |
|:--|:--|:--|:--|
| ffmpeg | 抽声音 | `ffmpeg -version` | Windows 可用 `winget install ffmpeg` |
| yutto | 下载 B 站视频 | `yutto --version` | `pip install yutto` |
| Python 3.10~3.12 | 跑转写 | `python --version` | 3.13 以上 funasr 可能装不上，要另装一个 3.12 |
| funasr + torch | 语音转文字 | `python -c "import funasr"` | 见 `scripts/transcribe.py` 开头说明（约 2~3GB） |

- 有 NVIDIA 显卡：转写很快，20 分钟音频几秒钟。
- 没有显卡：也能跑，慢很多（大概几分钟到十几分钟），提前跟用户说清楚。
- 用户只是偶尔扒一个视频、不想装这么多：先看第 1 步的"字幕捷径"，有官方字幕就不用装转写环境。

## 第 1 步：下载

先看看视频信息（标题、时长），确认值得扒：

```bash
curl -s "https://api.bilibili.com/x/web-interface/view?bvid=BVxxxx" -o info.json
```
（先存成文件再读，直接在终端打印可能因为表情符号报编码错误。）

只下声音：

```bash
yutto --audio-only -d "<输出文件夹>" "<B站视频链接>"
```

- **字幕捷径**：yutto 会顺带下载视频自带的字幕（.srt/.ass，如果有）。官方字幕比语音识别准，**有的话直接用字幕，跳过第 2、3 步**。
- Windows 上中文标题报编码错误：先设 `PYTHONUTF8=1` 再跑。
- 下载一直失败、连不上 `api.bilibili.com`：可能是 AI 工具的安全沙盒拦了网络，告诉用户需要放开网络权限再试。
- 本地已有视频文件：跳过这一步。

## 第 2 步：抽声音

```bash
ffmpeg -i "<输入视频或音频>" -vn -ac 1 -ar 16000 -c:a pcm_s16le "<输出.wav>" -y
```

Windows 上路径用 `D:/xxx` 这种写法。跑完**确认 wav 文件真的生成了**，有的环境路径写错也不报错。

## 第 3 步：转成逐字稿

```bash
python "<本skill目录>/scripts/transcribe.py" "<音频.wav>" --hotword-file "<热词.txt>"
```

- **热词**：把视频标题、简介里的专有名词、人名、术语，每行一个写进一个 txt。能明显提高准确率。没有就不传。
- 英文视频加 `--language en`。
- 产出：`<音频名>.txt`（逐字稿）+ `<音频名>_segments.json`（带时间戳）。
- 长音频转出来可能是一整行，先按句号切开再读。

## 第 4 步：整理成笔记

把逐字稿通读一遍，整理成 md，规矩是：

- **不是摘要，是整理**：保留讲解顺序、核心概念的定义、案例和数字、值得直接引用的原话。
- 英文视频整理成中文，专有名词保留英文原名。
- 语音识别的同音错字按上下文改掉，拿不准的标 `[听写存疑]`。
- 笔记开头写清楚：视频标题、作者、链接、时长。

**红线**：拿别人的视频内容做自己的分享或课程时，只借鉴思路和讲解顺序，**例子换成自己的真实经历**，不搬原话。
