# Word 文档自动插目录（TOC 域）

## 用途

给一份 .docx **插入真正的 Word 目录**——不是手打的假目录，是**能随正文变动自动更新页码**的 TOC 域。

**顺带解决一个高发问题**：很多人的方案标题只是"手动调大字号 + 加粗"，**Word 认不出来，插了目录也是空的**。这个 skill 会先体检，认出编号标题（`1` / `1.1` / `1.1.1`）并自动套上标题样式。

---

## ★先讲清一件事：Word 的目录是怎么来的

**Word 的目录不是"你写了什么"，是"它去收集用了标题样式的段落"。**

| 你的标题长什么样 | Word 认不认 | 结果 |
|:--|:--|:--|
| 套了「标题 1 / 标题 2 / 标题 3」样式 | ✅ 认 | 目录正常 |
| **只是手动调成三号字 + 加粗 + 居中** | ❌ **不认** | **目录是空的** |

> ⚠ **这是"我插了目录但是空白"的头号原因**，而写方案的人**绝大多数是手动调字号**，不用样式。
> **所以这个 skill 的第一步永远是体检，不是插目录。**

---

## 依赖

需要 `python-docx`（很小，几秒钟装完，不是 mineru 那种几个 G 的东西）：

```bash
pip install python-docx
```

**可选但推荐**（Windows + 装了 Word 时，能让目录页码自动生成，省掉手动按 F9）：

```bash
pip install pywin32
```

装不上看 `README.md`。

## 怎么做

### 第一步：先体检，别急着插

```bash
python scripts/add_toc.py --docx "方案.docx" --dry-run
```

输出会告诉你两个数：
- **已使用标题样式的段落：N 个** —— 这是 Word 真正认的
- **按编号识别到的疑似标题：M 个** —— 这是"长得像标题但没套样式"的

三种情况分别怎么办：

| 体检结果 | 怎么办 |
|:--|:--|
| 标题样式 > 0，编号候选 = 0 | ✅ 文档规范，直接插 |
| 标题样式 = 0，编号候选 > 0 | ⚠ **典型情况**：加 `--auto-style` 自动套样式再插 |
| 两个都是 0 | ❌ 认不出标题。**必须先在 Word 里手动套「标题 1/2/3」样式**，插了也是空的 |

### 第二步：插

```bash
# 文档已经规范用了标题样式
python scripts/add_toc.py --docx "方案.docx"

# 标题是手动加粗的（最常见）——自动套样式后再插
python scripts/add_toc.py --docx "方案.docx" --auto-style

# 只要一、二级目录
python scripts/add_toc.py --docx "方案.docx" --auto-style --levels 2
```

参数：
- `--docx`（必填）输入文件
- `--out` 输出路径，默认 `<原名>_带目录.docx`（**不覆盖原件**）
- `--levels` 收录到第几级，默认 3
- `--title` 目录页标题文字，默认「目　录」
- `--auto-style` 按编号自动套标题样式
- `--dry-run` 只体检不写文件
- `--no-update` 不调 Word 自动更新（默认会自动更新）

### 第三步：自动更新（默认就做了，不用管）

**这台电脑装了 Word 的话，脚本会自动调 Word 把目录和页码生成好，打开就能看到。**

原理：TOC 域的页码必须由 Word 排版引擎算，脚本自己算不出来。
所以脚本会在后台静默开一次 Word（`Visible=False`），刷新目录后保存退出。

```
[更新] Word 已自动刷新目录，共 1 个
[完成] 目录和页码已自动生成，直接打开就能看到，不用再按 F9。
```

#### 没装 Word 怎么办 —— 退回半自动

脚本会明确告诉你：

```
[提示] 这台电脑没装 Word（或缺 pywin32），没法自动更新页码。
       文档是好的，用 Word/WPS 打开后 Ctrl+A 再按 F9 即可。
       想自动更新的话：pip install pywin32
```

- **文档本身是好的**，只是页码要用户自己触发一次
- 加 `pip install pywin32` 就能变全自动（前提是这台机器装了 Office）
- 不想自动更新（比如不希望脚本动 Word）：加 `--no-update`

> ⚠ **半自动时那句"Ctrl+A 再按 F9"必须告诉用户**，否则他打开一看目录是空的，会以为工具坏了。

## ⚠ 必须知道的坑

| 坑 | 说明 |
|:--|:--|
| **目录是空的** | 99% 是标题没套样式。用 `--dry-run` 体检，再加 `--auto-style` |
| **页码空白** | 说明这台机器没装 Word/pywin32，走的是半自动。**Ctrl+A 再 F9** 即可 |
| 脚本卡在"更新"这一步 | Word 在后台被别的文档占着。关掉所有 Word 窗口重跑，或加 `--no-update` |
| **WPS 里可能显示不同** | WPS 对 TOC 域兼容性略有差异，以 Word 为准 |
| **`.doc` 不支持** | 先在 Word 里「另存为」`.docx` 再用 |
| **目录自己出现在目录里** | 本 skill 已规避——目录标题**故意不套** Heading 样式 |
| **自动套样式会改变外观** | 套上「标题 1」后字体字号跟随模板样式，**可能和原来手调的不一样**。这是正常的，而且更规范 |
| 原件安全 | 默认**另存新文件**，不动原件 |

## ⚠ 自动识别标题的规则与局限

只认 **`数字` 或 `数字.数字` 开头 + 分隔符 + 内容**，且整段不超过 60 字：
- ✅ 认：`1 编制依据`、`2.1 项目概况`、`3.1.2 成孔工艺`
- ❌ 不认：`第一章 编制依据`、`一、编制依据`、`（1）施工准备`

> 用「第一章」「一、」这类编号的文档，**只能在 Word 里手动套样式**，或先把编号改成阿拉伯数字形式。

## 三条纪律

1. **永远先 `--dry-run` 体检，把两个数字念给用户听**，让他知道文档现状再决定。
2. **看脚本最后一行怎么说**：
   - 说"已自动生成" → 直接让用户打开，**别再提 F9**（提了反而让人困惑）
   - 说"没装 Word" → **必须提醒 Ctrl+A + F9**，这是最容易让人以为出故障的一步
3. **不要覆盖原件。** 默认就是另存，别用 `--out` 指回原文件。
