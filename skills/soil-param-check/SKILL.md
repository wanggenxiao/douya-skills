# 土层参数体检

## 用途

拿到一张土层参数表，**逐项体检**，把可疑的数值挑出来，并说清楚"为什么可疑、原值可能是多少"。

**典型场景**：
- 地勘报告的参数表，转录成文字后要用，先查一遍有没有转错
- 接手别人的资料，快速看看数据靠不靠谱
- 自己录入完，找个"第二双眼睛"复核

> ⚠ **这个 skill 只负责"挑出可疑项"，不负责替你改数据。** 最终认定必须回原始报告核对。

---

## 怎么做

### 第一步：把表读成结构化数据
识别出每一层的：**层号 / 土层名称 / 重度 γ / 黏聚力 c / 内摩擦角 φ / 压缩模量 Es / 承载力特征值 fak / 层厚 / 其他**（孔隙比 e、含水率 w、标贯 N 等，有就取）。

- 表格可能来自 OCR，**列可能错位**。如果发现某一列的数值整体不符合该指标的量级，**优先怀疑是列串了**，而不是逐个报错。
- 缺项就留空，不要臆造。

### 第二步：单项范围校验

| 指标 | 常规范围 | 超出时的判断 |
|:--|:--|:--|
| 重度 γ | **16~22 kN/m³**（淤泥类可低到 15） | <14 或 >23 → 可疑。**出现 1.85 / 185 → 几乎必是小数点错位** |
| 黏聚力 c | 0~100 kPa（硬黏土可到 80） | **负数 → 必错**；>200 → 高度可疑 |
| 内摩擦角 φ | **0~45°** | **负数 → 必错**；>45 → 可疑；出现 400 → 小数点/量级错 |
| 压缩模量 Es | 2~50 MPa（软土 2~4） | <1 或 >100 → 可疑。**注意别和 kPa 混单位** |
| 承载力特征值 fak | 50~500 kPa | <30 或 >1000 → 可疑（岩石另论） |
| 层厚 | >0 | **=0 或负 → 必错**，多半是数据缺失 |
| 孔隙比 e | 0.4~1.5（淤泥可 >1.5） | <0.3 或 >2.5 → 可疑 |
| 含水率 w | 10%~60%（淤泥可更高） | <5% 或 >100% → 可疑 |
| 标贯击数 N | 0~50 击 | >60 → 可疑 |

### 第三步：★交叉校验（比单项范围更能抓出错）

单项都在范围内，但**互相矛盾**，照样是错。这几条最有用：

1. **砂土出现较大 c 值** → 可疑。无黏性土的 c 应接近 0，出现 c=25 kPa 多半是串行或串列。
2. **黏性土 φ > 30°** → 可疑。黏性土内摩擦角通常偏小，这么大往往是和砂层的数据串了。
3. **淤泥/淤泥质土却 γ 偏大** → 可疑。淤泥类重度应偏小（约 15~18），且孔隙比大、含水率高。
4. **重度与孔隙比矛盾**：孔隙比大（松散）的土，重度应该小。两者同时"大"是自相矛盾的。
5. **软土却 Es 很高 / 硬土却 Es 很低** → 可疑。
6. **层号不连续或重复**（①②④，或两个③）→ 多半是转录漏层/重层。
7. **同一土层在不同表里参数不一致** → 必有一处错。
8. **层底标高不单调递减 / 层厚与标高对不上** → 结构性错误。

### 第四步：输出

按这个格式，**先说结论、再列明细**：

```
【体检结果】共 N 层，发现 M 处可疑

⚠ 高度可疑（基本可判定为错）
1. ③层 淤泥质粉质黏土  γ=185 kN/m³
   → 远超常规 16~22，疑似小数点丢失，原值可能是 18.5

2. ⑤层 中砂  φ=-8°
   → 内摩擦角不应为负，疑似负号误加或转录错

🔍 需要复核（不一定错，但不合常理）
3. ④层 粉质黏土  φ=35°
   → 黏性土 φ 偏大，可能与相邻砂层数据串行，建议回原表核对

4. ②层 层厚=0m
   → 层厚不应为 0，疑似数据缺失

✅ 其余各层参数在常规范围内，且未发现交叉矛盾

【建议】上面 M 处请回地勘报告原件核对。
⚠ 本检查只看常识范围与内部一致性，不能替代原件复核。
```

---

## ⚠ 三条纪律

1. **不要替用户改数据。** 只说"疑似原值可能是 X"，改不改由他回原件确认。
2. **区分"必错"和"可疑"。** 负数、层厚为 0 这类是必错；φ=35° 的黏性土只是可疑——**混为一谈会让用户不信任你**。
3. **全在范围内也要明确说出来。** 输出"✅ 未发现异常"比沉默有价值——用户要的是"查过了"这个确认。

## 局限（必须告诉用户）

- 这是**常识范围校验**，不是原件比对。转录时如果一整列数据都错得"很合理"，查不出来。
- 特殊土（膨胀土、湿陷性黄土、红黏土、冻土、填土）的参数可能超出常规范围而仍然正确——**遇到这类土层，提示用户注意即可，别武断判错**。
- 岩石地基、复合地基的参数量级与土层不同，不适用本表。
