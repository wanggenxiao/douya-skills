# 工程文档目录生成

## 用途

**写方案最难的不是写，是不知道该写哪几章、有没有漏。**

这个 skill 做的事：你说清楚是什么工程、什么文档，它给出一份**结构完整、可直接粘进 Word** 的章节目录，每章附一句"这章要写什么"。

**适用文档**：施工方案 / 专项施工方案 / 施工组织设计 / 基坑监测方案 / 设计说明 / 技术交底 / 安全专项方案 / 应急预案。

---

## 第一步：先确认这四件事

不清楚就问，**别硬猜**（猜错了整份目录都白给）：

1. **什么文档**？（施工方案？监测方案？设计说明？）
2. **什么工程**？（基坑支护 / 桩基 / 边坡 / 管廊 / 降水 / 钢栈桥……）
3. **规模和特点**？（深度、面积、周边环境、有无地下水、有无特殊工艺）
4. **给谁看**？（报审 / 专家论证 / 内部交底 / 业主存档）—— 这决定详略和有没有"论证专用"章节

> ⚠ 如果用户只说了一句"给我出个基坑施工方案目录"，**至少要问回 2 和 3**，否则出来的是通用模板，没价值。

---

## 第二步：出目录

### 格式要求（直接决定能不能粘进 Word）

- **三级编号**：`1` / `1.1` / `1.1.1`，**阿拉伯数字加点，不要用"第一章""一、"混排**
- 每章标题后**空一行给一句要点提示**，用 `→` 开头，方便用户删
- **不要输出正文内容**，只出目录
- 末尾附「**本方案的特殊章节**」说明——即针对本工程特点额外加的那几章

### 通用骨架（以施工方案为例，按工程调整）

```
1 编制依据
  → 列规范、图纸、地勘报告、合同、批复文件，要写具体版本号
2 工程概况
  2.1 项目概况
  2.2 地质条件
  2.3 周边环境
  → 周边环境这节是专家最爱问的，管线、建（构）筑物、道路要写清距离
3 施工部署
  3.1 施工目标
  3.2 组织机构与职责
  3.3 施工顺序及流水段划分
  3.4 主要资源配置（人、机、料）
4 施工进度计划
5 主要分项工程施工工艺
  → 本章是主体，按实际工序拆分，每道工序：工艺流程 + 操作要点 + 控制指标
6 质量保证措施
7 安全文明施工措施
8 季节性施工措施
9 监测方案
10 应急预案
11 附图附表
```

### ★按工程类型该加的章节

| 工程类型 | 必须额外有的章节 |
|:--|:--|
| **基坑支护** | 土方开挖与支护工况配合、降水/止水、支撑（拆撑）施工、基坑变形控制 |
| **桩基** | 试桩、成孔工艺与泥浆控制、钢筋笼制安、灌注与充盈系数、桩基检测 |
| **边坡** | 坡面清理与危石处理、锚杆（索）施工与张拉锁定、格构/喷锚、坡面排水 |
| **管廊/沟槽** | 沟槽支护、地下管线保护、回填压实、闭水/闭气试验 |
| **降水** | 井点布置与成井、抽水试验、水位观测、回灌与地面沉降控制 |
| **钢栈桥/平台** | 结构验算、拼装与吊装、承载力试验、通行管理 |

### 监测方案的骨架（和施工方案不同，别套错）

```
1 编制依据
2 工程概况与周边环境
3 监测目的与依据
4 监测项目及测点布置
5 监测方法与仪器设备
6 监测频率
7 监测报警值与控制标准
  → 报警值要区分"累计值"和"变化速率"两项，专家必问
8 数据处理与信息反馈
9 异常情况处理措施
10 监测组织与质量保证
11 附图（测点平面布置图、剖面图）
```

---

## 第三步：收尾必说的两句

```
【本方案的特殊章节】
针对本工程 XXX 的特点，在通用框架外增加了：第 X 章 ……、第 Y 章 ……

【提醒】
本目录是按常规做法和规范惯例给出的框架，具体章节和详略请按你单位的模板、
当地主管部门/专家论证的要求再调一遍。报审前建议对照最新规范核一次编制依据。
```

---

## ⚠ 三条纪律

1. **不清楚就问，别硬出。** 通用模板哪都能搜到，价值在"贴着这个工程"。
2. **别写正文。** 用户要的是框架，你一写正文他还得删。
3. **必须提醒"按你单位模板再调"。** 各单位、各地方要求差别很大，不给这句话容易误导。

## 局限

- 各地方、各单位对方案章节的要求不同，本骨架是常规做法，**不是强制规范条文**。
- 专家论证、超危大工程的方案有额外的强制性要求，**遇到这类务必提醒用户按当地规定核对**。
